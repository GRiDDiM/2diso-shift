# 2DISO -SHIFT-

A shoot-'em-up where **you** shift reality: barrel-roll between four views of the same fight. Each view plays by different rules: a wall in one is open sky in another.

Made for **GitHub Game Off 2026** (theme: **SHIFT**).

## Status
Playable start to finish: ten stages from Earth to Planet X, each with its own boss, an ending with scrolling credits, then loop mode (keep your upgrades, loops get much harder). Earth, Mars, Jupiter and Planet X each hide a warp to a themed wave arena that drops you back at the next checkpoint. Finishing the game on Easy, Normal and Hard unlocks one ship skin each.

Also in the game: Boss Rush (every boss and miniboss back to back, timed), 36 achievements, Perfect Shifts, medals and ranks, wave-order targeting bonuses, 1UP drops, hills and slopes, two-player co-op and an AI wingman (RIVET-9). Built during November 2026 for the jam. See `DEVLOG.md` for how it was made.

## The four views
| View | What it is | What it flattens |
|---|---|---|
| SIDE | flat side-scroller | left/right. Anything in your lane hits you, whatever side it is on |
| ISO | isometric | nothing. True depth, with shadows |
| CHASE | over the shoulder | nothing. Best for threading holes |
| TOP | bird's-eye vertical rail | altitude. Ground targets and high decks are all on your level |

What a view flattens does not exist for collisions, so a wall in one view is open sky in another.

## Controls
| Action | Keyboard | Controller | Touch |
|---|---|---|---|
| Move | Arrows / WASD | D-pad | drag the left side |
| Fire | Space / Z / J | A | auto |
| Change speed (slow, cruise, fast, turbo) | V / F | B | SPEED |
| Bomb | X / K | Y | BOMB |
| Drone mode | C / L | X | DRONE |
| SHIFT view | Shift keys / Q E | L / R | L / R |
| Buy the lit upgrade | Enter / R | Select | UPGRADE |
| Pause | Esc / P | Start | II |

Upgrades: each pod moves the highlight one step along the bar (DRONE, SPREAD, LASER, WAVE, BOLT, MISSILE, SHIELD, ???); buy what is lit and the bar starts over. ??? is a wildcard: nuke, overdrive or god mode.

## Run it
It is plain ES modules, so it needs a web server: `npx serve .` then open the address it prints.
`node tools/sim.mjs 2` lets the autopilot play every level headless.

## Tech
Plain HTML5 + JavaScript (canvas 2D + Web Audio). No build step, no dependencies, no asset files: every line and every sound is generated in code.
